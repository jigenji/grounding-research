# AI グラウンディング手法マップ

現実世界の知識・構造をAIに橋渡しするための各種グラウンディング手法を網羅的に調査し、
技術原理・ユースケースの違いを可視化した「地図」としてまとめたリポジトリです。

## 対象手法（18手法）

| 群 | 分類 | 手法 |
|----|------|------|
| A | 形式的知識表現 | OWLオントロジー、ナレッジグラフ、タクソノミー/統制語彙、スキーマ/データモデル、形式論理/ルールエンジン |
| B | 検索・文書ベース | RAG各種(Naive/Advanced/Modular/Graph/Agentic)、平ドキュメント、エンベディング検索、構造化プロンプティング |
| C | リアルタイム接続 | ツール利用/MCP、デジタルツイン、マルチモーダルグラウンディング |
| D | 暗黙的・学習系 | ファインチューニング/RLHF、ガードレール/Constitutional AI |
| E | ハイブリッド・新興 | Graph RAG、セマンティックレイヤー、Feature Store、メモリシステム |

## 地図の読み方

各地図は異なる切り口でグラウンディング手法を配置しています。
1つの手法が複数の地図に登場し、それぞれの軸で異なる位置を占めることで、
手法の多面的な特性が理解できます。

### 地図1（意味の明示度 × 運用結合度）の要点

```
  形式性(高)
   │  知識の宝庫        デジタル統治
   │  (OWL,KG,論理)     (ツール/MCP,Graph RAG,デジタルツイン)
   │─────────────────────────────
   │  軽量スタート       ブラックボックス接続
   │  (平文書,プロンプト)  (マルチモーダル)
   └──────────────────────→ 結合度(高)
```

- **右上を目指す進化**: Naive RAG → Advanced RAG → Graph RAG → エージェンティックAI
- **ハイブリッド化が鍵**: 単独手法では右上に到達できず、複数手法の合成が必要

### 地図2（知識の抽象度 × 応答レイテンシ）の要点

- **設計時知識**（オントロジー、ルール）と**実行時知識**（RAG、ツール）の二層が最適
- ガードレールは「抽象原則をリアルタイム適用」する唯一の手法として特異な位置

### 地図3（データライフサイクル）の要点

- どの手法も単独ではライフサイクル全体をカバーできない
- エージェンティックAIが全ステージのオーケストレーターとして台頭
